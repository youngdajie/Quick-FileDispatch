3.5.4 修四处观感和交互问题。

## 更新弹窗不再贴一长串网址

「发现新版本」的弹窗正文里原来直接贴了发布页 URL，又长又断行。现在只留一句
「各版本的更新说明见 CNB 发布页」——关于页里本来就有可点的入口。

## 音频图标重新设计

之前是「圆角方块 + 挖出音符」，整体一个长方形，太冲。现在是**纯音符**：
两个圆符头 + 两根符杆 + 顶部斜横杠，不再套方块底。

## 列宽拖拽修好了，也更像 Windows

**为什么「大小」拖不动、「修改时间」能拖**：命中判定用的是
`e.target.closest('.lh-grip')`，而「大小」的把手骑在按钮右边缘，实际按在按钮的
padding 里就抓不到。现在改成**按坐标判定**——离分隔线中心 8px 内就算抓住，
不再依赖点在哪个元素上。

同时：

- 表头现在是**三条贯穿的竖分隔线**（名称 / 大小 / 修改时间之间），颜色用
  `--border-hover`，两套主题下都看得清（之前用最淡的 `--border-soft`，几乎看不见）
- 拖「名称」右侧的线：向左拖 = 名称变宽（大小列反向收窄），名称宽度也能调了
- **光标换成自绘的双箭头**：深灰箭头 + 白描边。之前用系统的 `col-resize`，
  浅色主题下是一只几乎看不见的白箭头
- 松手才写配置，拖完不会误触发「点列头排序」

## 浅色模式下的图标颜色

以前只有 6 个类型单独调过浅色，而且文件夹用的是偏土黄的 `#c07a12`，白底上发灰。
现在 16 个类型**统一**给了一套浅色专用色：更深、更饱和（文件夹 `#d97706`、
代码 `#0d9488`、PDF `#dc2626`…），白底上明显更精神。
