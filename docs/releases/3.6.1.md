3.6.1 是一次前端打磨，功能面不变。

## 启动画面

程序启动时先给一屏全屏过渡：自己的图标（蓝底白罗盘）浮现、罗盘图形归位、
产品名与一条细线依次亮起，随后整个遮罩淡出、工作区浮上来。
总时长控制在一秒出头，系统开了「减少动态效果」时只做淡入淡出。

## 昼夜切换

圆形揭幕，方向按目标主题走：

- 白天转深色：深色从点击处**扩散**盖掉白天
- 深色转白天：深色从四周**收回**点击处，露出的地方就是白天

黑转白动的是「旧快照」那一层，所以看到的是黑幕退回去，而不是白圆缩小、四周还剩黑。

## 主题：新增跟随系统

外观 → 主题现在是浅色 / 深色 / 跟随系统三张卡，一行排开。选「跟随系统」后，
Windows 切换应用模式时程序会跟着切 —— 系统那边改的是环境，不是用户在这里点了什么，
所以直接换色，不放揭幕动画。
顶栏那个按钮仍然是手动开关：点一下即离开跟随、钦定为当前的反色。

## 文件管理

- 再次进入页面改为**静默刷新**：不铺骨架屏、不清选择，数据没变连 DOM 都不重建，
  来回切页不再闪一下
- 左侧「云端 · 本地检测器」可以收起，收起时整块滑出、内容不重排，宽度让给文件区
- 文件区宽度只在收起/展开那一帧变化，动画过程中列表和网格不再逐帧重排

## 导航与图标

实心图标块改用主题强调色，深浅两套各自跟随；顶栏昼夜按钮悬停不再上移。

## 默认主题

出厂默认固定为白天，不再跟随 Windows 的应用模式。老配置里的选择原样保留。

## 网络代理

- 说明文案精简成一句
- 输入框右侧新增按钮：空着时扫描本机代理（先读 Windows 系统代理，再探常见端口），
  填了地址时变保存
- 只保存能解析成地址的值，填到一半不会被写进配置

## 关于页

- 运行环境只保留桌面外壳、Go 运行时、渲染引擎、操作系统、数据目录，
  数据目录右侧可直接打开所在文件夹
- 平台图标与配置卡片的色块比例对齐
- 若干文案按标点规则统一

## 版本

程序版本升级到 3.6.1。
