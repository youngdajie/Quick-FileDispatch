3.3.7 主要收拾界面细节。

## 关于页多了联系方式

作者那排链接加了 **B 站**、**Telegram** 和**电子邮件**的入口，链接之间用 `·` 分隔。

点「电子邮件」会交给系统去唤起邮件客户端。

> ⚠️ 注意：这一步走的是系统的 `mailto` 关联。如果你的 Windows 没设默认邮件程序
> （或者在「设置 → 应用 → 默认应用」里指向了一个已卸载的程序），点下去可能
> 没反应、或者跳去浏览器。**这不是程序的问题**——先在系统设置里指定一个
> 真实存在的邮件客户端，这个链接就会正常了。

## 勾叉都换成了矢量图标

主题卡片的勾、新手引导的步骤条、配置向导的检查结果，原来都是直接敲一个
`✓` / `✗` 字符——字体的粗细形状每台机器都不一样，有时候还会显示成别的字形。
现在统一成一套描边图标。

## 顶栏精简

去掉了顶栏那个「仓库状态」的小胶囊（显示 `owner/repo @ branch` 的那个），
信息在设置页和上传页都能看到，顶栏清爽一点。

## 其它

- 界面区块标题的上下留白放宽了一些
- 文件管理「新建文件夹」的提示文案调整（`git` 统一写成 `Git`）

## 安装

下载下方的 `QuickFileDispatch-Setup-3.3.7.exe` 双击安装即可。

- 系统要求：Windows 10 / 11（x64）
- CNB 平台写入依赖 Git（没装也能浏览云端，只是慢一些）
- 首次启动进新手指引：选平台 → 填仓库与令牌 → 映射本地目录
