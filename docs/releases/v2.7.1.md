把免费的代码托管仓库当**文件仓库**用：图片在本地用多核 CPU 压缩好再推上去，其他文件原样上传。

支持 **GitHub** 与 **CNB**（cnb.cool）双平台，基于 Electron 的 Windows 桌面应用。

## 这一版改了什么

- **链接规则跟着配置走。** 设置页一直写着「一份配置 = 仓库信息 + 本地目录 + 文件链接」，但链接规则和自定义域名实际是当成全局设置存的 —— 于是有两处不对：

  - 在几份配置之间切换时，链接规则会**变回默认值**。尤其 GitHub 切 CNB 时最明显：jsDelivr 这类规则是 GitHub 专属的，CNB 的下拉里根本没有它，表单只能回落成「自动」，一保存就把你选过的那条规则冲掉了。
  - **导出**配置时只带走当前生效那一份的规则，另外几份配置的规则全丢；导回来的时候又会被灌成同一条。

  现在链接规则和自定义域名存在每份配置自己身上，切换、导出、导入都跟着走；归档列表里每份配置也直接标出它用的是哪条规则。老配置会自动迁移：原来那条全局规则只还给适用的平台，不适用的退回「自动」，不会硬塞出一条打不开的链接。

  > 复制格式（纯链接 / Markdown…）和预览代理域名仍然是全局的 —— 前者是个人习惯，后者取决于你本机的网络环境，跟仓库无关。

- **默认规则换了。** 「自动」现在指的是：**GitHub 走 jsDelivr CDN，CNB 走 CNB 国内 CDN（JSDMirror）**。以前是各自的官方 raw 地址，国内直连时快时慢。想用别的（Raw Githack、GitHub Pages、自建域名…）在下拉里照旧可以单独选。

## 安装

下载下方的 `QuickFileDispatch-Setup-2.7.1.exe` 双击安装即可。

- 系统要求：Windows 10 / 11（x64）
- 建议装好 Git（用于本地仓库同步；没装也能浏览云端，只是慢一些）
- 首次启动进入新手指引：选平台 → 填仓库与令牌（现场验证）→ 映射本地目录
