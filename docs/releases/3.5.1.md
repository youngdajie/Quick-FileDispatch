把免费的代码托管仓库当**文件仓库**用：图片在本机用多核 CPU 压缩好再推上去，其他文件原样上传。

3.5.1 是一个补丁版，只修一处：左侧那条本地目录提示。

## 修：过时的提示一直挂着

3.5.0 里「本地目录非空且不是 Git 仓库」这类提示是**一次性写入、永不清除**的 ——
目录后来变成仓库、本地与云端已经一致了，红字还赖在左侧；点「检测」也没用，
因为那个按钮只刷新云端对比，完全不碰提示条。

现在提示条会**跟随真实状态**：

- 每次重画左侧、每次点「检测」、每次重新进入管理页，都复核一遍本地目录状态
- 状态恢复成 `ready`（本地已是这份配置的仓库）时，过时提示自动收起
- 两个数据源打架时以 `git:status` 为准 —— 它说本地是仓库了，就不再报「不是 Git 仓库」
- 空目录克隆完成后的绿色「已拉取」动效不会被立刻抹掉，播完再收起

## 安装

下载下方的 `QuickFileDispatch-Setup-3.5.1.exe` 双击安装即可。

- 3.4.9 起自带自动更新，装了 3.5.0 可以直接在关于页点「检查更新」升上来
- 系统要求：Windows 10 / 11（x64）
