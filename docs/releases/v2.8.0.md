把免费的代码托管仓库当**文件仓库**用：图片在本地用多核 CPU 压缩好再推上去，其他文件原样上传。

支持 **GitHub** 与 **CNB**（cnb.cool）双平台，基于 Electron 的 Windows 桌面应用。

## 这一版改了什么

- **非图片文件也能预览了，而且能改。** 以前文件管理页只有图片点得开，HTML、JS、CSS、JSON 这些只能双击甩给浏览器，改一个错别字得先下载、改完再用「用新文件替换内容」传回去。现在双击就打开：

  - **带语法着色**：JavaScript / TypeScript / HTML / CSS / JSON / Python / Go / Shell / YAML / Markdown / 各种配置文件（`.gitignore`、`.env`、`Dockerfile`…）各自有配色，深浅两套主题分别调过，白底黑底都看得清。
  - **就地编辑保存**：切到编辑态直接改，`Ctrl + S` 或点「保存」写回去。本地目录改的仍然要「提交并推送」才同步云端；云端改的直接生成一次提交。
  - **不弄乱文件**：读进来时记住原始换行符（CRLF / LF）和 BOM，保存时原样写回 —— 不然改一个字就会在 Git 里变成整个文件的重写。
  - **右上角一个按钮甩到浏览器**，还是按你配的链接规则生成地址。

- **看不了的情况会说清楚原因**，不是笼统失败：二进制文件、UTF-16 编码、超过 2 MB 的文件都会给出具体提示（图片、压缩包、安装包仍然走原来的「用系统程序打开」）。

- **中文 Windows 存的 GBK 文件不再是乱码。** 记事本「另存为 ANSI」出来的 HTML / CSS / bat / ini 都是 GBK 编码，以前按 UTF-8 硬解，打开就是满屏乱码 —— 很容易被误认成「CRLF 的问题」，其实同样是 CRLF，UTF-8 的没事、GBK 的才花。现在先严格按 UTF-8 解一次，失败就退 GB18030，内容正常显示、标题上标一个「GBK」。这类文件**只给看，不给改**：编码器只会写 UTF-8，改回去等于把整份文件从 GBK 换成 UTF-8，改一个错别字就能让 Git 里多出一次全文件重写。

- **配置项的卡片重新排过版式。** 以前仓库地址、别名、目录、状态挤成两三行还各自换行，看得乱。现在固定三行：平台与仓库一行、本地目录一行，「已归档 / 上次推送」这类状态信息单独放进一个小卡片里框起来，右边按钮不会跟着内容宽度乱跳。

- 顺手把弹层标题栏改成能挂按钮的版式，「标题 + 右侧动作」的排法以后别的弹窗也能用。

## 安装

下载下方的 `QuickFileDispatch-Setup-2.8.0.exe` 双击安装即可。

- 系统要求：Windows 10 / 11（x64）
- 建议装好 Git（用于本地仓库同步；没装也能浏览云端，只是慢一些）
- 首次启动进入新手指引：选平台 → 填仓库与令牌（现场验证）→ 映射本地目录
