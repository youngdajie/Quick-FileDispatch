## 修：点了「检查更新」报「检查失败」

**跟检测版本的代码没关系**：后端 `update:check` 实测是好的，能正确查到新版本、
拼出下载地址，那个地址也能正常下载。

真正的原因在前端：`about.js` 里用了 `confirmDialog()` 和 `err()`，
但导入行只写了 `{ $, escapeHtml }`。于是：

1. 点按钮 → `confirmDialog is not defined` → 进 catch
2. catch 里的 `err()` 也没导入 → 又抛一次 `ReferenceError`
3. 界面只剩一句「检查失败」，真正的错误被吞掉

ES Module 里漏导入的标识符只有运行到那一行才炸，语法检查发现不了；
而之前的界面验证只确认「按钮和通道存在」，从没真点过按钮，才一路漏到发版。

现在导入补齐了，并且：

- 新增静态检查 `check-imports.js`：扫描页面模块里用到却没导入的 `dom.js` 符号，
  发版前必跑（已做反证测试：去掉 import 会被立刻抓出来）
- 界面验证补了**真的点按钮**的流程：已是最新版 / 发现新版本弹确认框 /
  没有 ReferenceError
- 把 `update:check / download / progress / install` 补进通道清单 ——
  之前漏登记，启动时那句「已实现 52/52」其实少算了这四条，现在是 56/56
