把免费的代码托管仓库当**文件仓库**用：图片在本机用多核 CPU 压缩好再推上去，其他文件原样上传。

3.5.0 主要是把「切换主题」和「配置里绑定本地目录」这两处的手感理顺。

## 昼夜切换：点到即到

以前点太阳 / 月亮要等配置写完才换色，连点几下读到的还是旧状态，
看起来像「点了没反应、过一会儿连着跳」；那圈 0.62 秒的双向涟漪光晕
叠在一起也又慢又糊。

现在点下去**当场**换色：连点一次一变，全站几十处颜色渐变在切换那一瞬
全部掐掉（瞬时换色，不慢慢爬），配置写入合并成一次 —— 连点不会攒一堆重活。
涟漪光晕去掉了，只留一个 0.16 秒的图标缩放。

在当前目录下直接开新建弹窗，不用再点右键菜单。

## 配置：本地目录到底怎么落地

**以前的问题**：勾选了「打开管理页时自动拉取云端」，本地目录不是 Git 仓库时，
管理页左边能认出来「不是 Git 仓库」，但什么也没发生 —— 后端那一步直接跳过了。

现在把本地目录分成四种情况，各有明确的去处：

| 状态 | 行为 |
| --- | --- |
| **空文件夹** | 自动向云端拉取（克隆）。左侧提示「本地是空的文件夹（不是Git仓库本地目录），正在向云端拉取文件，请稍后」，完成后变绿打勾并自动收起 |
| **已是这份配置的仓库** | 按设置里的策略正常 pull |
| **别处的 Git 仓库**（有 .git 但 remote 对不上） | **直接报错**，绝不往里克隆，也不 pull 别人的仓库；新建 / 修改配置会拦在最后一步，显示红字并弹提示 |
| **非空又不是 Git 仓库** | 报错，请换一个空目录 —— 不覆盖你已有的文件 |

**配置向导最后一屏**：那句「点『克隆到此处』把仓库克隆到这个目录」不再是一行
红字了，做成了**可点的「克隆到此处」按钮**。点完就地拉取、就地重新验证，
结果行从 ✗ 变 ✓ 并播一个短动效。不想克隆也可以直接「完成」跳过 ——
进文件管理页时会自动拉取。

克隆会按**正在编辑的这份配置**取仓库和令牌（哪怕它还没激活），不会误拉当前
激活的那一份。

## 安装

下载下方的 `QuickFileDispatch-Setup-3.5.0.exe` 双击安装即可。

- 3.4.9 起自带自动更新，老版本可以直接在关于页点「检查更新」升上来
- 系统要求：Windows 10 / 11（x64）
- CNB 平台写入依赖 Git（没装也能浏览云端，只是慢一些）
