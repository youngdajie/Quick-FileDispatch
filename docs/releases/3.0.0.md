把免费的代码托管仓库当**文件仓库**用：图片在本机用多核 CPU 压缩好再推上去，其他文件原样上传。

**Go 重写后的第一个大版本**：从这一版起版本号不再带 `-go` 后缀——过渡期结束，这就是正式版。

## 新功能：首次启动跟随 Windows 主题

第一次启动时，程序会看一眼 Windows 的应用主题（设置 → 个性化 → 颜色）：Windows 是浅色就进浅色界面，深色就进深色界面。之后随时可以在设置里换，选过的会被记住，不会再被系统设置覆盖。

## 相对 Electron 版 v2.8.0 的窗口体验修复

这些修复在 2.8.1-go / 2.9.0-go 两个过渡版里陆续发布过，正式版一并带上：

- **首开白框**：第一次打开时窗口边上一圈原生白框——已修，首开就是干净的无边框窗口
- **标题栏拖动**：拖动、双击最大化 / 还原恢复正常
- **边缘缩放**：窗口四边 + 四角都能拉伸，页面铺满整个窗口，没有「接了一段别的底色」的段落感
- **四角圆角**：系统级圆角（Win11 的 DWM 合成，带抗锯齿），最大化自动变方角；Win10 上没有圆角但不影响使用
- **许可协议中文**：安装向导的许可协议页在英文原文前面加了中文译文

体积与过渡版一样：安装包约 7 MB，免安装单 exe 约 15 MB（Electron 版是 106 MB）。

## 安装

下载下方的安装包（约 7 MB，NSIS），照着向导装完即可；开始菜单、桌面快捷方式、
卸载入口都有。免安装党可以直接用单 exe 版（约 15 MB，双击直接跑）。

- 系统要求：Windows 10 / 11（x64），WebView2 运行时（Win11 自带，Win10 绝大多数已装）
- 建议装好 [Git](https://git-scm.com/)：本地同步要用它，没装也能浏览云端
- 配置目录与之前版本共用（`%APPDATA%\Quick-FileDispatch`），升级无需重新配置
