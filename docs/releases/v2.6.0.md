把免费的代码托管仓库当**文件仓库**用：图片在本地用多核 CPU 压缩好再推上去，其他文件原样上传。

支持 **GitHub** 与 **CNB**（cnb.cool）双平台，基于 Electron 的 Windows 桌面应用。

## 这一版改了什么

- **顶栏可以直接切昼夜，不用再进设置页**。图标显示的是「点了会变成什么」——深色下露太阳，浅色下露月亮。它和设置页那两张主题卡片共用同一份配置，从哪边切另一边都会跟着变。

- **浅色模式多了一层深空粒子背景**。缓慢漂移的星点加上近邻连线，透过面板能隐约看到，不影响读正文。深色模式下不跑：深色本身已经有层次，再叠一层只会显脏，还白耗电。

- **压缩完的图片能拉前后对比**。点队列或结果区的缩略图，弹出一张带中缝的对比图：左半是原图，右半是压缩后，按住中缝左右拖，就能看出压缩到底吃掉了哪些细节。

## 安装

下载下方的 `QuickFileDispatch-Setup-2.6.0.exe` 双击安装即可。

- 系统要求：Windows 10 / 11（x64）
- 建议装好 Git（用于本地仓库同步；没装也能浏览云端，只是慢一些）
- 首次启动进入新手指引：选平台 → 填仓库与令牌（现场验证）→ 映射本地目录
