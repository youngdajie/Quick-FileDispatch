把免费的代码托管仓库当**文件仓库**用：图片在本机用多核 CPU 压缩好再推上去，其他文件原样上传。

3.3.3 是一次**界面细节收尾**，把几处看着别扭的地方理顺。

## 改了什么

- **LFS 确认窗文案修正**：去掉了一对没生效的 Markdown 加粗符号
  （确认窗是纯文本，`**` 会原样显示成两个星号）。
- **配置卡片里的别名放大**：从 12.5px 提到 18.5px，名字更醒目。
- **「验证日期」小字垂直居中了**：之前和旁边的状态徽章没对齐。
- **删掉了字体设置右侧的「字体样例」**：一句静态示例文字，选完字体才
  变一下，没有实际用处，连代码一起彻底清掉了。

## 安装

下载下方的 `QuickFileDispatch-Setup-3.3.3.exe` 双击安装即可。

- 系统要求：Windows 10 / 11（x64）
- CNB 平台写入依赖 Git（没装也能浏览云端，只是慢一些）
- 首次启动进新手指引：选平台 → 填仓库与令牌 → 映射本地目录
