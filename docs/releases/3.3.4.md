把免费的代码托管仓库当**文件仓库**用：图片在本机用多核 CPU 压缩好再推上去，其他文件原样上传。

3.3.4 主要解决**自定义背景下的观感**：暗色壁纸的文字可读性、以及几处界面细节。

## 暗背景的文字不再糊

用偏暗的壁纸当浅色背景时，之前面板的白纱不够厚，文字会直接糊在图上。

现在白纱按图片亮度**逐级加厚**——图越暗纱越厚，而不是一刀切。实测一张大面积
纯黑的壁纸，面板白纱不透明度从 66% 提到 84%，标题和正文都立得住了。
亮图不受影响。

顺带：自定义背景下面板的边框、表头改成了**半透明**，背景图的气色能透出来，
不再是生硬的实心白。

## 界面细节

- **文件管理滑动加了渐隐**：列表滚到上下边缘时内容柔和淡出，不再被硬切一刀
- **关于页的链接**横排、hover 用主色描边勾勒（去掉下划线，下划线最像网页）
- **右下角提示条**左侧色条改成了实色竖条，和上传页那条统一，颜色更饱满
- **关掉了浏览器的表单自动填充**：不再弹出「已保存的内容」下拉框、也不会
  突然补一坨黄底蓝字——彻底去掉 Web 味

## 安装

下载下方的 `QuickFileDispatch-Setup-3.3.4.exe` 双击安装即可。

- 系统要求：Windows 10 / 11（x64）
- CNB 平台写入依赖 Git（没装也能浏览云端，只是慢一些）
- 首次启动进新手指引：选平台 → 填仓库与令牌 → 映射本地目录
