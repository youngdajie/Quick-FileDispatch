把免费的代码托管仓库当**文件仓库**用：图片在本机用多核 CPU 压缩好再推上去，其他文件原样上传。

3.2.0 是一次**界面与观感的大整理**：上传页重新分区、浅色模式换成自定义背景图 + 毛玻璃、
浅色不再画粒子，深色星野原样保留。功能逻辑没动，老配置直接可用。

## 图片设置：压缩与水印搬到上传页

「图片压缩」「水印」原本各自占设置页一张卡，可它们只在传图时才有意义，改一次要两头跑。
现在两类参数合并成上传页的**「图片设置」折叠区**（默认展开、点标题开合，开合状态记在本机）：

- 左边压缩：开关、质量、输出格式、最大宽高、目标体积、并行线程数、跳过策略
- 右边水印：开关、文字、位置、字号、不透明度、颜色（色板 + 十六进制 + 常用色）

设置页里那两张卡已移除；其它设置项照旧。

## 上传页版式

- 「待上传」队列**移到上传框正下方**，拖完文件视线不用往下找
- 任务项不再挂悬停提示——大小、尺寸、质量都摆在行里了，再弹一个气泡只会重复
- 复选框全部自绘：选中是主色渐变 + 白色小勾，未选中只描一圈淡边，hover 不会
  装作「已选中」（顺手修掉了「点了不变、鼠标移开才变」那个状态压盖的老问题）
- 折叠区收起时高度、间距、边框一并归零，不留残余

## 浅色模式：自定义背景图 + 毛玻璃

- **浅色不再渲染粒子**（白天不需要星野），改由设置 → 外观里的**自定义背景图**接管：
  选一张本机图片，程序会把副本存进配置目录，之后原图挪走删掉都不影响背景
- 新增**毛玻璃强度**滑块（0–24，0.1 一档）：给顶栏、侧栏、卡片加上背景模糊，
  数字越大越糊、面板越透出背景；拖动实时生效，拖到 0 就完全关掉
- 背景图偏暗时会**自动加厚白纱、提亮灰字**，避免正文糊在深色图上
- 深色模式完全不受这些影响，永远是星野

## 深色星野

- 保留原有的密度、速度与明灭节奏，一颗都没动
- 修掉「最小化再恢复 / 最大化切换后粒子挤在一角」：窗口尺寸变化、恢复可见、
  最大化状态翻转时都会按当前画布重新铺满
