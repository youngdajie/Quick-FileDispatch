把免费的代码托管仓库当**文件仓库**用：图片在本机用多核 CPU 压缩好再推上去，其他文件原样上传。

3.5.3 是四处手感和观感上的调整。

## 文件类型图标重做

以前是细描边风格，和图片缩略图摆在一起显轻、显小一号（列表里只有 18px）。

现在全部换成**实心圆角**图标：文件夹、图片、视频、音频、压缩包、代码、文本、
PDF / Word / Excel / PPT、字体、电子书、应用、数据库、兜底文件 —— 一律实心，
内部细节用挖空表达，单色也能看清。

尺寸也调了：列表里 18 → **28px**（和 30px 的缩略图同量级），网格里保持大图标。

## 列表列宽可以拖了

名称 / 大小 / 修改时间，像 Windows 资源管理器那样拖列边界调宽度：
「大小」「修改时间」标题右侧各有一条细线，鼠标移上去变蓝就能拖。
名称列自动吃剩余空间，所以三种宽度都能调。**松手后记住**，下次打开还是你调的样子。

## 文件管理页上传图片：压缩参数只剩一种

以前选「压缩」会问「沿用上传页参数 / 自定义参数」两套。
现在只留**沿用上传页参数**，自定义那套面板和相关代码都删了 ——
想改参数去上传页调，两处各自维护一套容易对不上。

## LFS 提示补了标点

「不占仓库额度）」后面补了逗号，「直链下载走对象存储」后面补了分号，
读起来不再是一口气连到底。

## 安装

下载下方的 `QuickFileDispatch-Setup-3.5.3.exe` 双击安装即可。

- 3.5.2 起自动更新恢复正常，可以直接在关于页点「检查更新」升上来
- 系统要求：Windows 10 / 11（x64）
