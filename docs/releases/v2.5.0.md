把免费的代码托管仓库当**文件仓库**用：图片在本地用多核 CPU 压缩好再推上去，其他文件原样上传。

支持 **GitHub** 与 **CNB**（cnb.cool）双平台，基于 Electron 的 Windows 桌面应用。

## 这一版改了什么

**文件管理页动得最多：**

- 双击文件名不再出现选词高亮（那一眼就看出是个网页）。鼠标移到条目上会轻轻放大，按下去缩回、松手弹回来。
- 选中不再「点哪选哪」。现在三条路：点左上角的勾选框、右键、在列表里按住左键拖框。普通单击只负责打开，不再顺手改选区。
- 框选不再只认空白处。条目上按住（或直接拖）一样能拉出选框，一片夹着文件的区域可以一次框住。
- 卡片上那条悬停才出现的工具条（复制链接 / 预览 / 重命名 / 替换 / 删除）删掉了，五个操作全部挪进右键菜单；菜单里还会显示当前用的是哪种链接格式。
- 「重命名 / 移动」的目录不再只能手打。本地与云端一致时，旁边会多一个「浏览…」，打开就是本地目录树，点着挑、或者按「选它」直接用；输入框下面那行会实时显示这个相对路径对应的本地真实路径。对不上时也会说清是哪一步没对上，而不是悄悄藏起按钮。

**设置页：**

- 点 GitHub / CNB 只切「正在编辑哪一份配置」，不再顺手把生效的配置也换掉。要换生效配置，请用右上角的归档配置下拉。
- 归档配置下拉里的条目挨得太紧，糊成一片，补了间距。
- 「仓库信息 + 本地目录 + 文件链接合成一份配置」那句说明从卡片标题旁挪出来，单独做成一张引导卡。

**其他：**

- 容量单位统一写成 GB（原来写的是 GiB）。
- 导出的配置文件名与 npm 包名统一成 `Quick-FileDispatch`（旧的 `jie-profiles-*.json` 仍然能导入）。

## 安装

下载下方的 `QuickFileDispatch-Setup-2.5.0.exe` 双击安装即可。

- 系统要求：Windows 10 / 11（x64）
- 建议装好 Git（用于本地仓库同步；没装也能浏览云端，只是慢一些）
- 首次启动进入新手指引：选平台 → 填仓库与令牌（现场验证）→ 映射本地目录
