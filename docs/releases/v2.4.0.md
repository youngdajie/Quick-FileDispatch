把免费的代码托管仓库当**文件仓库**用：图片在本地用多核 CPU 压缩好再推上去，其他文件原样上传。

支持 **GitHub** 与 **CNB**（cnb.cool）双平台，基于 Electron 的 Windows 桌面应用。

## 本次更新

- **界面字体** —— 不再只认一份写死的候选表，改成枚举本机真实安装的全部字体（一百多款，自己装的第三方字体也在内），下拉可输关键字筛选、右侧实时预览。**霞鹜文楷**成为程序主字体，没装则自动落到微软雅黑 UI
- **归档配置** —— 只有「填过仓库信息」的才算一份配置；切平台 / 点新建开出来的**空白落点**不再冒充成一份配置出现在列表里
- **下拉框** —— 去掉夹在一堆仓库名中间的 `──────` 假分隔项，改由样式画一条细分隔线；面板阴影与圆角一并重做
- **新手指引** —— 右上角新增 **❌**，不想走完可以随时退出，之后在设置页点「重看新手指引」还能打开
- **安装向导** —— 去掉只在安装那几分钟出现的自绘位图，安装包与产物名统一成 `QuickFileDispatch`

## 安装

下载下方的 `QuickFileDispatch-Setup-2.4.0.exe` 双击安装即可。

- 系统要求：Windows 10 / 11（x64）
- 建议装好 Git（用于本地仓库同步；没装也能浏览云端，只是慢一些）
- 首次启动进入新手指引：选平台 → 填仓库与令牌（现场验证）→ 映射本地目录

> 装好之后的快捷方式、开始菜单项、程序本体与卸载器都叫 **快捷文件分发服务`@JIE`**。

`@JIE` 里的 @ 后面是 JIE 三个字母，不是用户名。
