把免费的代码托管仓库当**文件仓库**用：图片在本地用多核 CPU 压缩好再推上去，其他文件原样上传。

支持 **GitHub** 与 **CNB**（cnb.cool）双平台，基于 Electron 的 Windows 桌面应用。

## 这一版改了什么

- **修掉图标「两副面孔」的问题**。上一版的 `icon.ico` 里混了两套设计：16 / 24 / 32 这三个小尺寸是从素材里直接取的「浅底 + 深蓝线」版本，48 往上才是「蓝底 + 白轮」。Windows 按需要挑尺寸，于是任务栏是蓝底、右键菜单和资源管理器的小图标却成了浅底，同一个程序看着不像一家。

  现在所有尺寸都从 1024 那张主图缩放生成，一套设计走到底；16 那档先做面积平均再补一次重采样，小尺寸下边缘不会出现一圈毛边。

## 安装

下载下方的 `QuickFileDispatch-Setup-2.6.2.exe` 双击安装即可。

- 系统要求：Windows 10 / 11（x64）
- 建议装好 Git（用于本地仓库同步；没装也能浏览云端，只是慢一些）
- 首次启动进入新手指引：选平台 → 填仓库与令牌（现场验证）→ 映射本地目录

> 装完如果任务栏还是旧图标，是 Windows 的图标缓存没刷新，重启资源管理器或注销一次即可。
