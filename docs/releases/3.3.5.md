把免费的代码托管仓库当**文件仓库**用：图片在本机用多核 CPU 压缩好再推上去，其他文件原样上传。

3.3.5 加了**新建文件夹**，并把几处细节理顺。

## 文件管理能新建文件夹了

在文件列表的空白处右键 → **新建文件夹**，直接建在当前目录下。

- 建的是**本地**目录（和改名、删除一样），改完在左侧点「提交并推送」才进仓库
- git 不跟踪空文件夹——里面放了文件才会出现在云端，弹窗里有提醒

顺带删掉了标题栏那个「本地目录」标签，它没什么信息量。

## 新手指引的下拉不土了

第一次启动的引导里，「链接规则」和「默认复制格式」两个下拉之前还是系统原生的样式，
和界面上其他地方对不上。现在换成和设置页同一套自绘面板。

## 进度条说清楚在干什么

上传前的**压缩**阶段，进度条之前会显示「上传中」（其实是本地在压图，还没开始传）。
现在压缩时显示「压缩中」并给出压缩百分比，真正上传时才显示「上传中」。
进度条左右也留出了边距，不再贴着边。

## 安装

下载下方的 `QuickFileDispatch-Setup-3.3.5.exe` 双击安装即可。

- 系统要求：Windows 10 / 11（x64）
- CNB 平台写入依赖 Git（没装也能浏览云端，只是慢一些）
- 首次启动进新手指引：选平台 → 填仓库与令牌 → 映射本地目录
