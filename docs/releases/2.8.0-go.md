把免费的代码托管仓库当**文件仓库**用：图片在本机用多核 CPU 压缩好再推上去，其他文件原样上传。

**这是 Go 重写的第一个版本，是骨架，还不是完整功能。**
从 2.8.0 起，这个项目全面转向 **Go + WebView2**：桌面外壳从 Electron 换成 Go（只用标准库），
安装包从 106 MB 缩到约 15 MB，单个 exe 免安装。Electron 版定格在 **v2.8.0**，不再更新。

## 这一版能干什么、不能干什么

界面与 Electron 版完全一致——同一份渲染层代码，深浅两套主题、压缩设置、
文件预览、新手引导全都在。

- **已经能用**：整个界面、本地配置读写、Git 仓库状态查看、本机字体枚举、应用外壳
- **还没接通**：云端上传 / 下载 / 列表、Token 落盘加密（DPAPI）、本地目录选择框

所以这一版**还传不了文件**，是给 Go 重写立的第一个桩。
日常用请下载 **v2.8.0（Electron 版）**，功能完整。

## 运行

下载下方的 `QuickFileDispatch-2.8.0-go.exe`（约 15 MB，单文件，免安装），双击直接跑。

- 系统要求：Windows 10 / 11（x64）
- 首次运行会开一个 Edge 应用窗口——这是过渡期的外壳，正式版会换成 WebView2 原生窗口
- 配置目录与 Electron 版共用（`%APPDATA%\Quick-FileDispatch`），两版互不影响
- 没装 Git 也能开界面；Git 仓库状态相关功能需要本机有 Git
