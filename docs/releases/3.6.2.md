3.6.2 把两套几乎重复的引导合成一套，补齐文件管理里缺的东西，并让四种预览框成套。

## 启动引导

新手指引和「新建配置」合并成同一套向导。程序只在第一次创建运行目录时弹一次，
之后都能在设置页「新建配置」里调用。设置页那个「重看新手指引」按钮去掉了。

## 文件管理

- 双击视频 / 音频不再甩给浏览器，内置播放器：播放/暂停、可拖动进度条、时间显示，
  没有音量（用系统音量就够）。浏览器解不了的容器会说明原因，并给「在资源管理器中显示」
- 首次进入不再闪骨架屏：右侧读本地目录，几十毫秒就回来了，直接铺内容；
  真正慢的时候（超过 350ms）才补骨架
- 「正在核对云端与本地」的加载态只放在左侧检测器上，不再让整页陪着等
- 工具栏去掉「返回上级」（面包屑可以点）和「从云端拉取最新」（进页面本来就会拉）

## 四种预览框

图片、视频、音频、文本的弹层共用一套标题栏按钮和圆角阴影，但各自按内容形态
自适应宽度：

- 图片 / 视频按画面比例来（横图宽、竖图窄），上限 1100px，深色主题用深色展台，
  浅色主题用浅灰展台
- 音频是 440px 窄卡，音符封面 + 控制条
- 文本保持 1080px 宽屏，代码要横向空间

右上角统一是「复制链接 / 浏览器打开」，文本预览再多个「编辑」。复制链接按
文件管理页选的链接格式来（纯链接 / Markdown / HTML），弹层开着的时候换格式也能跟上。

## 首页

展开「上传选项」会平滑展开并滚到内容区顶部，收起时原路滚回。

## 链接格式

去掉 BBCode。老配置里存着 bbcode 的会自动换成 Markdown（配置版本升到 11）。

## 细节

禁用按钮不再有 hover 反应（之前划过会「蓝 → 灰 → 蓝」闪一下）；主题连点在同一个
tick 里连点也不会算错方向；设置页换过主题后顶栏按钮仍能正常落盘。

## 版本

程序版本升级到 3.6.2。
