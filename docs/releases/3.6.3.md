3.6.3 修好了首次进文件管理页的空白问题，并下线了已经没人用的自定义背景图。

## 首屏不再空白

以前首次进文件管理页，右侧要等 git 同步完才列目录；远端不可达时几秒都没文件，
左侧也只有一句静态文字、连加载遮罩都不出来。

现在列本地目录和云端检测并行：右侧文件第一时间铺出来（实测 100ms 内），
左侧遮罩压在最前面、转圈常驻至少 600ms，检测完再收起。

## 移除自定义背景图

设置页「自定义背景图」、面板不透明度滑块、智能调整，以及配套的毛玻璃渲染层
全部删除。前端、IPC 通道、主进程处理器、配置字段和老配置迁移一并清理，
配置版本升到 12（老配置里那两个字段会被自动删掉）。

浅色模式回归扁平面板 + 细边框的观感；深色模式一直是星野，不受影响。
