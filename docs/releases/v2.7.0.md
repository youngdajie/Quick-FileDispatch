把免费的代码托管仓库当**文件仓库**用：图片在本地用多核 CPU 压缩好再推上去，其他文件原样上传。

支持 **GitHub** 与 **CNB**（cnb.cool）双平台，基于 Electron 的 Windows 桌面应用。

## 这一版改了什么

- **修掉「配置一多，切换配置后界面就卡住不动」的问题。** 症状是切到另一份配置后，界面上的任何操作短时间内都没反应，CNB 的配置尤其明显。

  查下来跟配置数量其实没关系（实测连切 14 份，切换动作本身只要几毫秒），是三件事叠在一起：

  1. 主进程里有几处同步的目录遍历（列目录、统计文件数、生成目录树）。Electron 的界面请求都要在主进程排队，主线程被占住，界面就整块停摆 —— 所以现象是「点哪儿都没反应」，而不是某一个功能慢。
  2. 「Git 在不在、本地目录干不干净」这类查询没有缓存。切一份配置会连着重画两三次页面，每次重画都要问一遍，而单次查询要起 6 个 git 进程、耗时 200~380 毫秒；云端那一路还会递归统计整个仓库。
  3. 每切一次配置都会重新检测一次仓库状态，CNB 的检测要走一次网络请求，连点几份配置时这些请求会叠在一起。

  现在按仓库身份加了短缓存（同一件事并发只跑一次，写完立刻作废），目录遍历全部改成异步。实测：git 状态查询 304ms → 1ms 以内，仓库统计 44ms → 1ms 以内，连续切配置时主进程最长停顿 29ms，界面全程可点。

- **安装包小了一圈（110MB → 102MB）。** 原来打包进了 Electron 全部语言包（48MB），实际只用得上中文和英文，裁掉之后体积小 7.5%，功能没有任何变化。

## 安装

下载下方的 `QuickFileDispatch-Setup-2.7.0.exe` 双击安装即可。

- 系统要求：Windows 10 / 11（x64）
- 建议装好 Git（用于本地仓库同步；没装也能浏览云端，只是慢一些）
- 首次启动进入新手指引：选平台 → 填仓库与令牌（现场验证）→ 映射本地目录
